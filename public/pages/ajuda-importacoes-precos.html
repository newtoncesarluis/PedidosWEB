Visão geral

As importações permitem carregar planilhas Excel (.xlsx) em lote para acelerar implantação ou atualização massiva. Todas seguem o mesmo padrão: carregar arquivo → mapear colunas → validar → importar.

Acesse em Cadastros → Ferramentas do Cadastro ou menu de importação dedicado.

Fluxo comum de importação

  1. Prepare a planilha com cabeçalho na primeira linha (nomes de coluna claros).
  2. Abra a tela de importação correspondente.
  3. Arraste o arquivo ou clique em Selecionar arquivo.
  4. O sistema exibe prévia das linhas — confira encoding e separadores.
  5. Mapeie cada coluna da planilha para o campo do sistema (dropdown por coluna).
  6. Execute Validar — linhas com erro aparecem destacadas (documento duplicado, campo obrigatório vazio).
  7. Corrija a planilha ou ignore linhas inválidas.
  8. Clique em Importar — aguarde resumo (inseridos, atualizados, erros).

Importação de Clientes

  1. Cadastros → Importação de Clientes.
  2. Campos típicos: nome/razão social, CNPJ/CPF, endereço, cidade, UF, CEP, telefone, e-mail, vendedor, região, segmento.
  3. CNPJ duplicado gera alerta — escolha atualizar existente ou pular linha.
  4. Após importar, rode Geocodificação em Manutenção de Cadastros para clientes aparecerem no mapa.
Veja também Ajuda: Cadastrar Clientes para regras de campos obrigatórios.

Importação de Fornecedores

  1. Cadastros → Importação de Fornecedores.
  2. Mapeie nome da fábrica, CNPJ, contatos, condições básicas.
  3. Validação checa duplicidade por documento ou nome.
  4. Complete tabelas de preço e condições manualmente após importação, se a planilha não trouxe esses vínculos.

Importação de Preços

Tela: Cadastros → Preços → Importação de Preços. O processo segue 4 etapas fixas mostradas na barra superior: 1) Fornecedor → 2) Arquivo → 3) Mapeamento → 4) Importar.

  1. Selecione o fornecedor primeiro — o upload do arquivo fica bloqueado até escolher um fornecedor no combo.
  2. Arraste o Excel/CSV na faixa tracejada ou clique em Selecionar arquivo (.xlsx, .xls, .csv).
  3. Use ⬇ Modelo Excel para baixar uma planilha de exemplo já com os cabeçalhos = campos configurados para a tabela produto (útil para preparar a planilha da fábrica no formato certo).
  4. Mapeie cada coluna da planilha para um campo do sistema (dropdown por coluna) — botão ⚡ Essenciais tenta mapear automaticamente os campos obrigatórios.
  5. Clique em 🔍 Validar Dados — cada linha recebe um status: Atualizar (produto já existe pelo código de fabricante), Sem Alteração, ou Sem Cadastro (produto novo, será inserido). Cards de contagem aparecem no topo da tabela e funcionam como filtro.
  6. Marque "Não gravar itens sem cadastro" se quiser importar só atualizações, ignorando produtos novos.
  7. Clique em 💾 Salvar Produtos — uma tela de progresso mostra inseridos/atualizados/erros em tempo real; é possível abrir o detalhamento de cada grupo ou exportar a lista de erros em CSV.
Se a planilha tiver a coluna estoque_atual, a importação também grava um lançamento de ajuste de estoque (saldo anterior → saldo novo) no histórico de movimentação do produto — não é só uma atualização de cadastro.

Importar preço direto para a Tabela de Preços (sem alterar o cadastro do produto)

Quando o fornecedor selecionado tem tabela(s) de preço vinculada(s), aparece o painel "Gravar preços nas tabelas vinculadas a este fornecedor" antes de carregar o Excel.

  1. Marque a opção para ativar este modo — os campos de preço do cadastro do produto (vlr_venda, precoa, ipi, st, icms, etc.) não são gravados; só a tabela de preço escolhida recebe o valor.
  2. Mapeie a coluna de preço da planilha para a tabela desejada; clique em "+ Coluna de preço para outra tabela" para mapear o mesmo Excel para várias tabelas ao mesmo tempo (preços diferentes por coluna).
  3. Escolha o tipo de desconto por tabela: valor em R$ ou em %.
  4. Se existir uma tabela padrão automática configurada no sistema (tabela marcada como padrão + "atualizar automaticamente"), produtos novos importados sem mapeamento explícito de tabela recebem o preço de referência nela automaticamente.
  5. Produto novo nesse modo entra no cadastro com os preços da ficha zerados — o preço "oficial" do produto fica só nas tabelas escolhidas.

Configurar Campos de Importação

Cadastra quais campos do produto ficam disponíveis no dropdown de mapeamento da tela de Importação de Preços — não é um "perfil" por fornecedor, é a lista de campos válidos para a tabela produto.

  1. Cadastros → Configurar Campos de Importação.
  2. Cada registro define: nome do campo no banco, apelido exibido no mapeamento, tipo (texto, moeda, decimal, inteiro) e se é obrigatório.
  3. Campos podem ser desativados (excluído) sem perder o histórico de configuração.
  4. O botão de download Modelo Excel na tela de importação usa esses campos para montar os cabeçalhos da planilha de exemplo.
Não existe seleção de "perfil salvo por fábrica" — o mapeamento de colunas é feito manualmente a cada importação (o botão ⚡ Essenciais agiliza mapeando os campos obrigatórios automaticamente).

Coluna Categoria na planilha de preços

A planilha da fábrica pode ter uma coluna chamada categoria (ou similar). Mapeie-a para o campo Categoria/Segmento durante a importação — o valor é salvo no campo segmento do cadastro do produto.

Comportamento automático

  • Se o valor da categoria não existir na tabela de categorias do sistema, ele é criado automaticamente com status Ativo.
  • Se já existir, apenas o campo segmento do produto é atualizado — nenhuma categoria duplicada é criada.
  • Os valores são gravados em maiúsculas (padrão do sistema).

Como mapear na importação

  1. Acesse Importação de Preços e carregue a planilha.
  2. Na etapa de mapeamento de colunas, localize a coluna da categoria na planilha.
  3. No dropdown correspondente, selecione Categoria/Segmento.
  4. Execute a importação — o sistema processa e cria as categorias novas automaticamente.
  5. Após importar, verifique as categorias criadas em Cadastros → Categorias.
Após a importação, os produtos ficam filtráveis por categoria na busca do pedido. Veja Ajuda Produtos → Categoria / Segmento.

Tabela de Preços — cadastro manual

  1. Cadastros → Preços → Tabela de Preços.
  2. Liste tabelas existentes ou clique em Nova.
  3. No formulário: descrição, fornecedor vinculado, vigência, status ativo/inativo.
  4. Aba/grid de itens: adicione produtos com preço unitário, desconto máximo, IPI quando aplicável.
  5. Busque produto por código ou descrição — preço salva ao confirmar linha.
  6. Vincule a tabela ao fornecedor em Relações do Fornecedor para aparecer nos pedidos.
  7. Vincule ao cliente para Vitrine Digital usar preços corretos.

Após importar — checklist

  • Clientes: geocodificar endereços (Manutenção)
  • Produtos: conferir fotos e fornecedor padrão
  • Preços: testar um pedido com a tabela importada
  • Fornecedores: configurar condições de pagamento aceitas
