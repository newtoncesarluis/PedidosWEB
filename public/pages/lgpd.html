📋 Sobre a LGPD
Lei 13.709/2018 — LGPD. Toda empresa que armazena dados pessoais de pessoas físicas (nome, CPF, e-mail, telefone, localização) precisa registrar a base legal do tratamento. Use este painel para registrar consentimentos, exportar dados a pedido do titular e anonimizar cadastros quando necessário.

📋 LGPD — O que o sistema faz

🔵 Registro de consentimento
Salva na tabela lgpd_consentimentos que o titular autorizou o armazenamento dos seus dados, com data, responsável e origem (cadastro manual, formulário web, importação).
🔴 Revogação
Registra a data de revogação do consentimento. Os dados continuam no banco (necessário para obrigações legais e contratuais), mas o sistema passa a indicar que o cliente revogou.
📥 Exportação
Gera um arquivo JSON com todos os dados do titular: cadastro, pedidos, visitas e histórico de consentimentos. Entregue ao cliente quando ele exercer o direito de acesso (Art. 18, II).
🚫 Anonimização
Substitui nome, CPF, e-mail e telefone por valores neutros. O histórico de pedidos é mantido (apenas vinculado a um ID anônimo). Irreversível — use somente quando o titular exigir exclusão definitiva (Art. 18, VI) e não houver obrigação legal que impeça.
⚠️ Importante: A LGPD não exige consentimento para todas as hipóteses de tratamento. Contratos, obrigações legais e interesse legítimo também são bases válidas. O consentimento aqui registrado é opcional, mas recomendado como boas práticas.
