Visão geral

Configurações ficam no menu Configurações — restritas a administradores ou perfis com permissão específica. Alterações aqui afetam todos os usuários da instalação.

Configurações do Sistema

Parâmetros gerais da operação, organizados em seções colapsáveis.

  1. Configurações → Config. do Sistema.
  2. Revise cada bloco: pedidos (numeração, status padrão), financeiro, e-mail, backup, integrações.
  3. Altere valores e clique em Salvar no bloco correspondente.
  4. Algumas opções exigem reinício do serviço ou novo login para aplicar.
Anote valores anteriores antes de mudar parâmetros críticos (ex.: numeração de pedido).

Tipo de Pedido Padrão

Na seção Pedidos existe o campo Tipo de Pedido Padrão. Ao selecionar um tipo aqui, ele será pré-selecionado automaticamente sempre que o vendedor abrir um novo pedido.

  1. Acesse Configurações → Config. do Sistema.
  2. Expanda a seção Pedidos.
  3. Localize o campo Tipo de Pedido Padrão — o combo lista todos os tipos ativos cadastrados em Tabelas de Apoio → Tipos de Pedido.
  4. Selecione o tipo desejado e clique em Salvar Configurações.
Regras de prioridade ao abrir novo pedido:
1. Se a empresa tiver fluxo ORÇAMENTO, o tipo é fixado em Orçamento (independente do padrão).
2. Caso contrário, o tipo configurado aqui é aplicado automaticamente.
3. Se nenhum padrão estiver configurado, o sistema seleciona o primeiro tipo disponível (ou "PEDIDO" quando existir).
Para cadastrar ou editar tipos de pedido acesse Cadastros → Tabelas de Apoio → Tipos de Pedido.

EuAtendo (ApiChat) — como configurar

  1. No painel do EuAtendo, abra o cadastro da sua conexão WhatsApp e copie o token de autenticação (o mesmo usado como Bearer na API).
  2. No sistema, acesse Configurações de API e informe a senha administrativa para desbloquear.
  3. No card WhatsApp — API de Envio, mude o Provedor de envio para EuAtendo (plataforma hospedada, Bearer token).
  4. URL da API: deixe em branco (usa https://apichat.euatendo.app). Só preencha se o EuAtendo indicar outro endereço.
  5. Cole o Token da Conexão e clique em Salvar.
  6. Informe o seu celular em Número para teste (formato 5514999999999 — DDI + DDD + número) e clique em Testar Conexão. O teste envia uma mensagem real para esse número.
  7. Mensagem chegou? O selo verde «ApiChat liberado» aparece no card — a integração está pronta.
Selo de status do ApiChat:
🟢 ApiChat liberado — o último teste de envio funcionou (mostra data/hora).
🟡 Aguardando validação — token salvo, mas ainda sem teste aprovado. Use «Testar Conexão».
Ao trocar o token, o selo volta para amarelo até um novo teste passar — o verde nunca fica desatualizado.

EuAtendo — como utilizar no dia a dia

  1. Depois de liberado, nada muda na rotina: nas telas de pedido, use Enviar → WhatsApp normalmente.
  2. O PDF do pedido vai em anexo automaticamente, com a mensagem como legenda — o cliente recebe sem você abrir o WhatsApp.
  3. Na home, o botão do WhatsApp fica verde com o status «● ApiChat EuAtendo» — não há QR Code para escanear nem instância para conectar.
  4. As mensagens saem do número conectado no painel do EuAtendo (o mesmo para todos os vendedores).
  5. Todo envio fica registrado no cliente: na tela de Clientes, botão Histórico → seção Mensagens Enviadas (data, canal, destino, quem enviou e status — inclusive falhas com o motivo). Vale para WhatsApp (qualquer provedor) e e-mail.
  6. Para conferir ou trocar o token, volte em Configurações de API.
O EuAtendo cobre o envio de mensagens. Recursos que dependem de receber mensagens (bot do vendedor, captura de Instagram DM) continuam usando a Evolution API.
Para enviar mensagens em massa (promoções, reativação de clientes), use Vendas → Campanhas WhatsApp — guia completo em Ajuda: Campanhas WhatsApp.

Evolution API — como configurar

  1. Em Configurações de API, mantenha o provedor em Evolution API.
  2. Informe a URL da Plataforma e a API Key Global da sua instalação Evolution e clique em Testar Conexão / Salvar.
  3. Na tabela Usuários — Instâncias WhatsApp, clique em QR Code no vendedor, dê um nome à instância e escaneie com o WhatsApp do celular dele.
  4. Status CONECTADO = pronto. Cada vendedor envia pelo próprio número.
  5. Se a sessão cair (badge cinza), gere um novo QR Code e escaneie de novo.
Sem API configurada, o envio manual ainda funciona via link wa.me com o texto formatado — mas aí o PDF precisa ser anexado à mão na conversa.

Marca da instalação (Parâmetro Locais)

  1. Configurações → Marca da instalação.
  2. Upload de logo exibida em relatórios, vitrine e login.
  3. Defina nome fantasia, cores ou textos de rodapé conforme campos disponíveis.
  4. Salve — limpe cache do browser se logo não atualizar imediatamente.

LGPD — Gestão de Consentimento

  1. Configurações → LGPD.
  2. Registre bases legais e termos aceitos pelos usuários/contatos.
  3. Consulte log de consentimentos e exporte quando solicitado por auditoria.
  4. Links públicos de privacidade/termos ficam em /privacidade.html e /termos.html.

Perfis de Acesso

  1. Cadastros → Perfis de Acesso (permissão acessoperfil ou perfil administrador).
  2. Liste perfis existentes ou clique em Novo Perfil.
  3. Distribua permissões S/N nas abas: Pedidos/Clientes, Fornec./Produtos, Outros Cadastros, Restrições de Pedido, Permissões Gerais e Importação.
  4. Vincule usuários ao perfil em Usuários → aba Acesso.
  5. Perfil 1 = administrador — acesso amplo independente dos campos S/N.
Após alterar um perfil, peça ao usuário para fazer login novamente — o menu e as telas leem as permissões da sessão.

Permissões — módulo Cadastros e telas principais

As permissões abaixo ficam em Cadastros → Perfis de Acesso. Controlam o que aparece no menu lateral, na busca global, no app mobile e se a tela abre ou exibe «Acesso Restrito».

Campos novos de Acessar tela (tela_*) entram com padrão S em perfis antigos após atualização. Campos de Incluir / Alterar / Excluir entram com padrão N — libere explicitamente quem pode cadastrar.
