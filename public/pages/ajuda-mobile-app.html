Visão geral

O SysRepWeb funciona como PWA (Progressive Web App): pode ser instalado na tela inicial do celular e operar parcialmente sem internet. Ideal para representantes em rota.

Instalar no celular (PWA)

  1. No Chrome (Android) ou Safari (iOS), acesse a URL do SysRepWeb e faça login.
  2. Android: menu ⋮ → «Instalar app» ou «Adicionar à tela inicial».
  3. iOS: botão Compartilhar → «Adicionar à Tela de Início».
  4. O ícone SysRepWeb abre em tela cheia, sem barra do browser.
  5. Mantenha o app atualizado — ao abrir online, o service worker baixa versões novas.

Modo app (mobile shell)

A URL /mobile-shell.html oferece navegação simplificada para representante: timeline de atalhos, pedidos, clientes, rotas, mapa.

  1. Na home desktop, use «Versão mobile» ou acesse diretamente o mobile shell.
  2. Menu inferior ou timeline abre telas em iframe otimizado para touch.
  3. Botão «Versão completa» retorna à home administrativa (se perfil permitir).

Pedidos offline — preparação

Guia detalhado: Ajuda Pedidos Offline. Resumo:

  1. Com Wi‑Fi, abra Pedidos → prepare o pacote offline (clientes, produtos, tabelas da carteira).
  2. Aguarde conclusão — indicador mostra quantos registros foram baixados.
  3. Ative modo avião ou entre em área sem sinal.
  4. Crie pedidos normalmente — ficam na fila local (IndexedDB).

Sincronizar pedidos offline

  1. Conecte-se a Wi‑Fi estável (hotel, escritório).
  2. Abra Pedidos → painel offline → Sincronizar fila.
  3. Aguarde envio de cada pedido — erros (produto inativo, cliente bloqueado) aparecem por item.
  4. Corrija e reenvie falhas; sucessos viram pedidos normais no servidor.
  5. Repita «Preparar offline» antes da próxima viagem para dados atualizados.

Rotas e visitas no celular

  • Minhas rotas — executar paradas, GPS, check-in (Ajuda CRM)
  • Mapa de Operações — visão do gestor; vendedor usa Minhas rotas
  • Pânico do Vendedor — heatmap de clientes em risco no mobile
  • Leads — cadastro rápido de prospect após visita

Consulta de Estoque no celular

Permite ao vendedor verificar o saldo de estoque dos produtos diretamente no campo, sem precisar acessar o desktop.

  1. No menu Mais (ícone ☰), toque em Consulta de Estoque.
  2. Se o botão não aparecer, o administrador precisa ativar o parâmetro habilitarestoque = S em Configurações do Sistema.
  3. Digite o nome ou código do produto no campo de busca.
  4. O badge colorido indica o nível de estoque:
    🟢 Verde — estoque acima do mínimo
    🟡 Amarelo — estoque igual ou abaixo do mínimo cadastrado
    🔴 Vermelho — zerado ou negativo
    ⚪ Cinza — sem informação de estoque
O estoque exibido é o do banco de dados em tempo real. Para bases legadas Delphi, o saldo é o mesmo exibido no ERP.

Financeiro do Cliente no celular

O vendedor pode consultar os títulos em aberto de um cliente antes ou durante a visita, sem precisar ligar para o escritório.

  1. Na lista de Clientes, toque no menu ⋮ do cliente desejado.
  2. Selecione Financeiro.
  3. A tela exibe os títulos em aberto, vencidos e o total por categoria.
  4. Use as abas para filtrar: Em aberto, Vencidas ou Todas.
Os títulos vêm da tabela Contas a Receber. Se não aparecer nada, verifique se os lançamentos estão associados ao código do cliente correto.

Bot WhatsApp do Vendedor

O vendedor pode consultar pedidos, financeiro de clientes e meta do mês enviando mensagens de texto para o número do sistema via WhatsApp — sem abrir o app.

ComandoO que retorna
ajudaLista completa de comandos
statusResumo do dia: pedidos e valor total
pedidosSeus pedidos de hoje
pedidos NOMEÚltimos 5 pedidos de um cliente
metaAtingimento da meta do mês atual
cliente NOMEInformações do cliente na sua carteira
fin NOMETítulos em aberto de um cliente
  1. O administrador configura o webhook /api/webhook/wa-vendedor na Evolution API (evento messages.upsert).
  2. O telefone WhatsApp de cada vendedor deve estar preenchido no campo Telefone Secundário do cadastro de usuário.
  3. O bot identifica o remetente pelo número e só responde a vendedores cadastrados.
  4. Números não reconhecidos são silenciosamente ignorados.
Sem custo de API de IA — o bot usa regras simples e lê diretamente do banco de dados do sistema.
