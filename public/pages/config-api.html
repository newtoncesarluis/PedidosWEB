Facebook Lead Ads Captura automática
Como funciona: Quando alguém preenche um formulário do seu anúncio no Facebook ou Instagram, o lead entra automaticamente no CRM com origem "Facebook Ads" — sem nenhuma ação manual.
Cole esta URL em Meta for Developers → Webhooks ao configurar o app
Cole este token no campo "Verify Token" ao configurar o Webhook no Meta for Developers
Gere em Meta for Developers → Tools → Graph API Explorer com permissão leads_retrieval e pages_read_engagement
▸ Como configurar no Meta for Developers (passo a passo)
  1. Acesse developers.facebook.com e crie um App (tipo: Business)
  2. Adicione o produto Webhooks ao app
  3. Escolha o objeto Page e clique em Subscribe to this object
  4. Cole a URL do Webhook e o Verify Token acima — clique em Verify and Save
  5. Após verificar, assine o evento leadgen
  6. Em Graph API Explorer, gere um Page Access Token com permissões leads_retrieval e pages_read_engagement
  7. Cole o Page Access Token acima e salve
  8. Teste com a Leads Ads Testing Tool do Meta para confirmar que o lead chega no CRM
