3
Deploy do código
Sempre que houver atualização no sistema

O deploy envia o código do SysRepWeb para o VPS e reinicia o processo automaticamente.

🦇
Abrir o bat

Servidor_Projetos.bat → [A] SysRepWeb → [1] Deploy → Hostinger

📦
O que o deploy faz automaticamente

Gera o pacote .tar.gz (sem node_modules/.env/logs) → envia via SCP → extrai no servidor → npm install → pm2 reload

⚠️ O arquivo .env do servidor não é sobrescrito pelo deploy — suas configurações ficam preservadas.
4
Variáveis de ambiente (.env)
Configuração do servidor — feito uma única vez

O arquivo /root/pedidosweb/.env no servidor contém as configurações do sistema.

Configurações essenciais do .env
PORT=3002
NODE_ENV=production
TRUST_PROXY_HOPS=1

# Banco de licenças (Oracle/remoto)
LICENSE_DB_HOST=147.15.106.135
LICENSE_DB_PORT=3306
LICENSE_DB_NAME=sistema_licencas
LICENSE_DB_USER=nilton
LICENSE_DB_PASSWORD=kzf010557f

# Senha do painel de licenças e API Keys
DEV_PASSWORD=mudar@123
💡 Para editar o .env no servidor: bat → [1] SSH → nano /root/pedidosweb/.env
Após editar: pm2 restart pedidosweb --update-env
⚠️ Sempre use --update-env ao reiniciar após alterar o .env, caso contrário o PM2 ignora as novas variáveis.
5
Criar banco MySQL para o cliente
Repetir para cada novo cliente

Cada cliente precisa de um banco de dados próprio. Criamos a estrutura a partir do banco do Poliitens (template).

1️⃣
Conectar ao servidor via SSH

bat → [1] SSH

2️⃣
Exportar estrutura do banco template
SSH
mysqldump -u root -pNRE_Mysql2025 --no-data nc_poliitens > /root/estrutura_template.sql
3️⃣
Criar banco e importar estrutura
SSH — substitua nc_CLIENTE pelo nome real
mysql -u root -pNRE_Mysql2025 -e "CREATE DATABASE nc_CLIENTE CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -pNRE_Mysql2025 nc_CLIENTE < /root/estrutura_template.sql
4️⃣
Criar usuário MySQL para o cliente
SSH — substitua nc_CLIENTE e senha_CLIENTE
mysql -u root -pNRE_Mysql2025 -e "
  CREATE USER 'nc_CLIENTE'@'localhost' IDENTIFIED BY 'senha_CLIENTE';
  CREATE USER 'nc_CLIENTE'@'%' IDENTIFIED BY 'senha_CLIENTE';
  GRANT ALL PRIVILEGES ON nc_CLIENTE.* TO 'nc_CLIENTE'@'localhost';
  GRANT ALL PRIVILEGES ON nc_CLIENTE.* TO 'nc_CLIENTE'@'%';
  FLUSH PRIVILEGES;"
💡 Padrão de nomenclatura: banco = nc_SLUG · usuário = nc_SLUG · senha = SLUG@ANO
Exemplo: banco nc_smp · usuário nc_smp · senha smp@2026

🗄️ Passo 1 — Criar banco MySQL

Conecte ao servidor via bat → [1] SSH e rode os comandos abaixo substituindo CLIENTE pelo slug do cliente (ex: smp, farma, acme):

# 3. Importar estrutura
mysql -u root -pNRE_Mysql2025 nc_CLIENTE < /root/estrutura_template.sql

# 4. Criar usuário MySQL
mysql -u root -pNRE_Mysql2025 -e "
  CREATE USER 'nc_CLIENTE'@'localhost' IDENTIFIED BY 'SENHA';
  CREATE USER 'nc_CLIENTE'@'%'         IDENTIFIED BY 'SENHA';
  GRANT ALL PRIVILEGES ON nc_CLIENTE.* TO 'nc_CLIENTE'@'localhost';
  GRANT ALL PRIVILEGES ON nc_CLIENTE.* TO 'nc_CLIENTE'@'%';

Erros comuns e soluções
Problemas encontrados durante a configuração
ErroCausaSolução
502 Bad Gateway pedidosweb caiu ou Nginx aponta para porta errada pm2 restart pedidosweb --update-env e verificar porta no Nginx
Origem não permitida pelo CORS Domínio não está na lista de origens permitidas Domínios *.nresolutions.com.br são permitidos automaticamente no código
Access denied for user root LICENSE_DB_* vazio no .env Preencher credenciais do banco de licenças no .env e reiniciar com --update-env
401 Unauthorized na API Key Chave inválida ou licença inativa Verificar se a licença está ativa no painel e se a chave está correta
Bloqueado por 15 min Muitas tentativas de login erradas pm2 restart pedidosweb no servidor para limpar o bloqueio
PM2 com 4kb de memória Processo reiniciando em loop (erro no .env) Ver logs: pm2 logs pedidosweb --lines 20 --nostream
Unknown database Nome do banco digitado errado Verificar: mysql -u root -pNRE_Mysql2025 -e "SHOW DATABASES;"
