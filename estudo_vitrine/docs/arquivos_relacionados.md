# Arquivos relacionados no SysRepWeb original

Referencia dos pontos usados para extrair a demonstracao:

- `server.js`: publica `/vitrine/:token` e monta `/api/vitrine`.
- `routes/vitrine.js`: API original da Vitrine Digital.
- `public/vitrine.html`: pagina publica de catalogo/carrinho.
- `public/pages/clientes.html`: botao e modal para gerar link pela tela de clientes.
- `public/home.html`: atalho da Vitrine Digital na home.
- `public/mobile-shell.html`: modal host para uso no shell mobile.
- `public/pages/ajuda-clientes.html`: documentacao da Vitrine Digital.

Neste estudo, o foco foi reduzido para:

- produtos
- clientes
- tabela de preco vinculada ao cliente
- token/link da vitrine
- pedidos gerados pela vitrine
